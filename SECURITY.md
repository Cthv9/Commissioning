# Sicurezza

## Versioni supportate

Riceve correzioni di sicurezza solo l'**ultima versione pubblicata** (vedi [Releases](https://github.com/Cthv9/Commissioning/releases)). Chi installa dal Microsoft Store la riceve in automatico; chi usa il setup deve installare la nuova versione.

## Segnalare una vulnerabilità

Non aprire una issue pubblica. Usa la segnalazione privata di GitHub: scheda **Security** del repository, pulsante **Report a vulnerability**.

Indica, se possibile:

- versione dell'app (Impostazioni, icona ℹ️) e sistema operativo;
- come riprodurre il problema;
- che cosa permette di fare (leggere o modificare dati, eseguire codice, bloccare l'app…).

## Che cosa succede dopo

| Fase | Tempi indicativi |
|---|---|
| Conferma di ricezione | entro 5 giorni lavorativi |
| Prima valutazione (è una vulnerabilità? quanto è grave?) | entro 10 giorni lavorativi |
| Correzione e nuova versione | il prima possibile, in base alla gravità |

La correzione viene pubblicata in una nuova versione. La descrizione del problema viene resa pubblica (GitHub Security Advisory) solo dopo che la correzione è disponibile, dando credito a chi l'ha segnalato se lo desidera.
